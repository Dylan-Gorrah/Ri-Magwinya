# Play Store

Everything needed to list Ri-magwinya on Google Play.

| File | What it is |
|---|---|
| [`store-listing.md`](store-listing.md) | Name, short and full description, category, data safety answers, release notes |
| [`privacy-policy.md`](privacy-policy.md) | The POPIA privacy notice. Play needs it at a public URL |
| [`screenshots.md`](screenshots.md) | The 8 phone screenshots to take, and how |
| [`icon-512.png`](icon-512.png) | 512 × 512 store icon |
| [`feature-graphic-1024x500.png`](feature-graphic-1024x500.png) | 1024 × 500 feature graphic |
| [`src/render.py`](src/render.py) | Re-renders the icon, the feature graphic and the launcher icons |
| `app-release.aab` | Signed bundle, v1.1.0. Attached to the GitHub Release, not committed |

A Play Console screenshot is only needed with a Google Play developer
account (the brief says "if applicable"). The signed AAB is ready to upload
to one.
