# The collection code

Back to [[Ri-magwinya]]

Four digits. The entire handover mechanism.

## What it's for

Staff need to know that the person in front of them is the person who placed
the order, in about two seconds, without asking for a student card.

A number the student can read off a screen — or off the notification, or from
memory — does that. **4 7 2 9**, staff find it on the queue, food goes over
the counter.

## Where it lives

`orders.collection_code`, `char(4)`.

Generated by `place_order` inside the transaction that creates the order, so
an order never exists without one.

## How unique it has to be

**Unique among today's open orders.** Open meaning not yet `collected`, not
`cancelled`, not `no_show`.

That's a much smaller pool than it sounds — realistically a few dozen orders
at once against 10,000 possible codes. Collisions are rare, and when one does
come up the function just picks another number and tries again.

It deliberately isn't globally unique. Yesterday's 4729 and today's 4729 have
nothing to do with each other, and nothing is looked up by code alone — staff
find the card on the queue and check the number matches what's on it.

## Why four digits and not something cleverer

A QR code would be more secure and much worse. It needs the student's screen
to be awake, clean, and bright enough, plus a scanner on the staff side, plus
a fallback for when any of that fails. In a twenty-minute break, in the sun,
the fallback would become the main path within a week.

Four digits can be **said out loud**. That's the feature.

Guessing one gets you someone else's food only if you also know their order
exists, are standing at the counter during their slot, and the staff member
doesn't notice the name on the card is different. The failure mode is "one
sandwich", not "the till".

## How it's shown

**On the student's order screen**, as four separate tiles — `CodeTiles` in
[[The design system]] — big, with a spring animation as they land. It's the
screen they'll hold up at the counter, so the code is the biggest thing on it.

```
  ┌───┐ ┌───┐ ┌───┐ ┌───┐
  │ 4 │ │ 7 │ │ 2 │ │ 9 │
  └───┘ └───┘ └───┘ └───┘
     Order #1047
```

**On the staff queue**, on the card, next to the student's name.

**In the notification**, so it's readable from the lock screen without opening
anything. See [[Notifications]].

## Order number vs collection code

Two different numbers, and they're easy to confuse:

| | `order_number` | `collection_code` |
|---|---|---|
| Looks like | `#1047` | `4729` |
| Comes from | `generated always as identity` | random, in `place_order` |
| Unique | forever | among today's open orders |
| For | referring to an order — receipts, support, the sales export | proving it's yours at the counter |

The order screen shows both. The notification leads with the code.
