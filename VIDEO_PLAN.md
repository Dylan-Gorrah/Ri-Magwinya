# Demo video — the flow

Just the taps, in order. Say what you are about to do, then do it.

**Accounts:** student `user123@gmail.com` / `FrogybyD1` · staff
`admin@gmail.com` / `Admin1234!`

---

## Start

- [ ] Open the app on the welcome screen
- [ ] Say who you are, what the app is, and that it is Kotlin + Supabase on a real phone

## Pick a role

- [ ] Tap **I am a student**

## Create an account

- [ ] Tap create account
- [ ] Try it empty → error
- [ ] Bad email → error
- [ ] Short password → error
- [ ] Passwords that don't match → error
- [ ] Fill it in properly → you land on the menu
- [ ] On the laptop: the new user in Supabase, and the password stored as a hash

## Sign in again

- [ ] Sign out
- [ ] Wrong password → error
- [ ] Right password → back in
- [ ] Close the app and reopen → still signed in

## Order something

- [ ] Show the menu with live stock
- [ ] Open **Vetkoek** → 2 vetkoeks, 2 polony, 1 cheese → **R17.00**
- [ ] Add to cart
- [ ] Add **fried chips**, pick **Large** → **R40.00**
- [ ] Open the cart, pick a collection time
- [ ] Checkout → show the wallet balance → place the order
- [ ] Show the 4-digit code and the progress
- [ ] On the laptop: the new order row, and the stock dropped

## Show one thing failing

- [ ] Try to order more than the wallet holds → "you are short R…"
- [ ] Or open a sold-out item → it won't open

## Staff side

- [ ] Sign out, sign in as staff
- [ ] The order is already in the queue
- [ ] Start preparing → Mark ready → Mark collected
- [ ] Student's screen updates on its own
- [ ] Stock: change a number → it changes on the student menu
- [ ] Sales: revenue, the chart, top sellers
- [ ] Top up a wallet

## Settings

- [ ] Open Profile
- [ ] Dark mode on → changes straight away
- [ ] Edit profile → change the name, add a phone → save
- [ ] Empty name → blocked
- [ ] Close and reopen → it stuck
- [ ] On the laptop: the updated profile row

## Offline

- [ ] Airplane mode on → friendly message, no crash
- [ ] Airplane mode off → it recovers

## Exit

- [ ] Sign out → back at the welcome screen
- [ ] One line recap, then thanks for watching
